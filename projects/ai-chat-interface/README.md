# AI Chat Interface 🤖

A modern, responsive, and interactive chat interface showcasing clean frontend styling, state management, and real-time streaming simulations. Designed to mirror state-of-the-art AI chatbots like ChatGPT and Claude.

## 🚀 Live Features
* **Real-time Streaming Output**: Simulates API server-sent events with chunks of text printed dynamically.
* **Intelligent Keyword Matching**: Detects topics such as "REST API", "React", or "Tailwind" to respond with production-ready templates.
* **Auto-resizing Input Area**: Dynamically expands input container based on multiline message inputs.
* **Responsive Sidebar Navigation**: Switch chats or start new sessions smoothly.
* **Markdown & Code Rendering**: Parses code-blocks, lists, and bold strings dynamically.

## 🛠️ Technology Stack
* **HTML5**: Semantic tags for sidebar, headers, main wrappers, and forms.
* **CSS3 (Vanilla)**: Features Flexbox, custom scrolls, responsive queries, and elegant dark gradients.
* **JavaScript (ES6+)**: Custom stream engines, state tracking, and simple DOM parsing algorithms.

## 📦 Getting Started
1. Clone this repository or open the project folder.
2. Open `index.html` directly in any web browser.
3. Type topics like **"Write a REST API routing structure"** or **"React performance"** into the input field to test keyword responses.
